## 2. `mock-llm` profile

- 目的：CI 与 E2E 不依赖真实模型、零成本、确定性。
- 实现：`@Profile("mock-llm")` 注册 `ChatModel` 假实现，按请求中的「任务标记」（System Prompt 头部注释 `{# task: plan #}`）返回预置 JSON / 文本（`src/test/resources/mock-llm/*.json`）；Embedding 返回文本哈希生成的伪向量；Rerank 按关键词重合度打分。
- 工具调用：mock 模型根据脚本决定是否发起 `tool_calls`，以覆盖审批流。

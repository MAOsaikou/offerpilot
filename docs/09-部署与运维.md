# 09 · 部署与运维

## Windows 本地前后端查看入口

根目录统一入口为 `OfferPilot.cmd`，双击打开菜单。首次安装并打开 Docker Desktop，选「8 配置 DeepSeek」，再选「1 启动全部」；后续更新选「4 更新前端」或「5 重建并重启后端」。旧 CMD 逐个收纳到 `deploy/windows/legacy/` 并转发统一入口。操作说明见 [Windows 使用说明](../deploy/windows/README.md) 和 [后端启动说明](../backend/README.md)。PostgreSQL、Flyway、JPA、Redis 均保留，开发期默认文字档位接 DeepSeek。

统一入口复用 `deploy/windows/backend-preview.ps1`，以 dev profile 绑定 127.0.0.1:8081。如果 8081 已监听，保留原进程并提示，不接管也不停止它。菜单「2 停止前后端」核对 PID、启动时间与可执行路径后停止已管理 Java 进程，再停止本项目 Nginx；数据库容器继续运行。日志和进程元数据保存在 D:\OfferPilot。

菜单「4 更新前端」调用 `deploy/windows/prepare.ps1` 构建前端并下载官方 Windows Nginx，产物在 `D:\OfferPilot\nginx-1.31.5\`；「6 仅启动前端」执行配置校验与重复启动检测。访问 `http://localhost:8080`。

- Nginx 只绑定本机回环地址，静态资源与 SPA 路由回退同域访问；`/api/` 转发 `127.0.0.1:8081`，关闭 SSE 缓冲，600 秒读取超时。
- `/actuator/health`、`/v3/api-docs` 和 Swagger 页面转发到后端，便于检查联调。后端未启动时前端仍可用，健康检查和对话明确报告连接失败。
- `OfferPilot.cmd -Action stop-frontend` 只向本项目 Nginx 发送优雅退出，不结束其他 Nginx 实例；`prepare.ps1` 无递归清理，仅覆盖构建输出与本项目配置。
- 后端与数据库仍是独立进程：按本文及 backend README 启动。`nginx.exe` 不会启动 Java、数据库或模型服务。当前 Agent 为真实 DeepSeek 单轮 HTTP/SSE 聊天，尚未接入编排或历史持久化。
- 修改前端后重跑准备脚本；若使用已有 Nginx，可传 `-NginxDirectory`，该目录须在 `D:\OfferPilot\` 内。前端生产构建固定使用 `/api/v1` 且禁用 MSW。
- 官方 Windows 安装与控制命令参考 https://nginx.org/en/docs/windows.html ，下载来自 https://nginx.org/en/download.html 。

> 目标：新机器 10 分钟内一键启动；公网 HTTPS 演示在评审期可用率 ≥ 99.5%；所有密钥仅经环境变量注入。

## 2. Docker Compose（`deploy/docker-compose.yml`）

```yaml
name: offerpilot

services:
  caddy:
    image: caddy:2-alpine
    restart: always
    ports: ["80:80", "443:443"]
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile:ro
      - frontend_dist:/srv/frontend:ro
      - caddy_data:/data
      - caddy_config:/config
    environment:
      DOMAIN: ${DOMAIN:-localhost}
    depends_on: [backend]

  frontend:
    build:
      context: ../frontend
      args:
        VITE_API_BASE_URL: ${VITE_API_BASE_URL:-/api/v1}
    image: offerpilot/frontend:${TAG:-latest}
    volumes: [frontend_dist:/dist]         # 仅负责产出静态文件到共享卷
    command: ["sh", "-c", "rm -rf /dist/* && cp -r /app/dist/. /dist/ && echo done"]
    restart: "no"

  backend:
    build: ../backend
    image: offerpilot/backend:${TAG:-latest}
    restart: always
    env_file: [../.env]
    environment:
      SPRING_PROFILES_ACTIVE: prod
      JAVA_TOOL_OPTIONS: "-XX:MaxRAMPercentage=70 -XX:+UseZGC -Dfile.encoding=UTF-8"
    depends_on:
      postgres: { condition: service_healthy }
      redis: { condition: service_healthy }
      minio: { condition: service_started }
      jobs-mcp: { condition: service_started }
    healthcheck:
      test: ["CMD", "wget", "-qO-", "http://localhost:8081/actuator/health"]
      interval: 30s
      timeout: 5s
      retries: 5
      start_period: 60s
    deploy:
      resources: { limits: { memory: 1600m } }

  jobs-mcp:
    build: ../mcp-servers/jobs-mcp
    image: offerpilot/jobs-mcp:${TAG:-latest}
    restart: always
    environment:
      PORT: 7001
      CACHE_TTL_SECONDS: 600
      MAX_PARALLEL_SITES: 6
    deploy:
      resources: { limits: { memory: 256m } }

  postgres:
    image: pgvector/pgvector:pg17
    restart: always
    environment:
      POSTGRES_DB: ${POSTGRES_DB:-offerpilot}
      POSTGRES_USER: ${POSTGRES_USER:-offerpilot}
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
    command: >
      postgres -c shared_buffers=512MB -c maintenance_work_mem=256MB
               -c max_connections=100 -c hnsw.ef_search=64
    volumes: [pg_data:/var/lib/postgresql/data]
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U $${POSTGRES_USER} -d $${POSTGRES_DB}"]
      interval: 10s
      timeout: 5s
      retries: 10
    deploy:
      resources: { limits: { memory: 768m } }

  redis:
    image: redis:7-alpine
    restart: always
    environment:
      REDIS_PASSWORD: ${REDIS_PASSWORD:?REDIS_PASSWORD must be set}
    command: ["sh", "-c", "exec redis-server --appendonly yes --maxmemory 100mb --maxmemory-policy allkeys-lru --requirepass \"$${REDIS_PASSWORD}\""]
    ports: ["127.0.0.1:6379:6379"]
    volumes: [redis_data:/data]
    healthcheck:
      test: ["CMD-SHELL", "redis-cli --no-auth-warning -a \"$${REDIS_PASSWORD}\" ping"]
      interval: 10s
      timeout: 3s
      retries: 10

  minio:
    image: quay.io/minio/minio:latest
    restart: always
    command: server /data --console-address ":9001"
    environment:
      MINIO_ROOT_USER: ${MINIO_ROOT_USER}
      MINIO_ROOT_PASSWORD: ${MINIO_ROOT_PASSWORD}
    volumes: [minio_data:/data]
    deploy:
      resources: { limits: { memory: 256m } }

volumes:
  pg_data: {}
  redis_data: {}
  minio_data: {}
  caddy_data: {}
  caddy_config: {}
  frontend_dist: {}
```

本地开发只启动依赖：`docker compose --env-file backend/.env.local -f deploy/docker-compose.yml up -d postgres redis minio jobs-mcp`。

## 3. Dockerfile

### 3.1 backend

```dockerfile
# backend/Dockerfile
FROM maven:3.9-eclipse-temurin-21 AS build
WORKDIR /app
COPY pom.xml ./
COPY offerpilot-*/pom.xml ./
RUN mvn -q -B -pl offerpilot-bootstrap -am dependency:go-offline
COPY offerpilot-* ./
RUN mvn -q -B -pl offerpilot-bootstrap -am -DskipTests package

FROM eclipse-temurin:21-jre-alpine
WORKDIR /app
RUN addgroup -S app && adduser -S app -G app
COPY --from=build /app/offerpilot-bootstrap/target/*.jar app.jar
USER app
EXPOSE 8081
ENTRYPOINT ["java", "-jar", "app.jar"]
```

### 3.2 frontend

```dockerfile
# frontend/Dockerfile
FROM node:22-alpine AS build
WORKDIR /app
RUN corepack enable
COPY package.json pnpm-lock.yaml ./
RUN pnpm install --frozen-lockfile
COPY . .
ARG VITE_API_BASE_URL=/api/v1
ENV VITE_API_BASE_URL=$VITE_API_BASE_URL
RUN pnpm build

FROM alpine:3.20
COPY --from=build /app/dist /app/dist
```

（静态文件由 Caddy 托管；若不用 Caddy，可改为 `nginx:alpine` 并挂载 `nginx/default.conf`。）

## 4. 反向代理

### 4.1 Caddyfile（推荐，自动 HTTPS）

```caddyfile
{$DOMAIN} {
    encode zstd gzip

    # SSE：关闭缓冲、延长超时
    @sse path /api/v1/agent/chat /api/v1/agent/runs/* /api/v1/*/analyze /api/v1/*/optimize /api/v1/interviews/* /api/v1/discovery/recommendations /api/v1/career/*
    handle @sse {
        reverse_proxy backend:8081 {
            flush_interval -1
            transport http {
                read_timeout 600s
                write_timeout 600s
            }
        }
    }

    handle /api/* {
        reverse_proxy backend:8081
    }
    handle /mcp* {
        reverse_proxy backend:8081 { flush_interval -1 }
    }
    handle /actuator/health {
        reverse_proxy backend:8081
    }
    handle /swagger-ui* {
        reverse_proxy backend:8081
    }
    handle /v3/api-docs* {
        reverse_proxy backend:8081
    }

    handle {
        root * /srv/frontend
        try_files {path} /index.html
        file_server
        @assets path /assets/*
        header @assets Cache-Control "public, max-age=31536000, immutable"
        header /index.html Cache-Control "no-cache"
    }

    header {
        Strict-Transport-Security "max-age=31536000"
        X-Content-Type-Options nosniff
        X-Frame-Options DENY
        Referrer-Policy strict-origin-when-cross-origin
        Permissions-Policy "camera=(self), microphone=(self)"
    }
}
```

## 6. 环境变量说明

完整模板见仓库根目录 [.env.example](../.env.example) 与 [frontend/.env.example](../frontend/.env.example)。

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `DOMAIN` | 公网必填 | 演示域名，Caddy 自动申请证书 |
| `POSTGRES_DB` / `POSTGRES_USER` / `POSTGRES_PASSWORD` | 是 | 数据库 |
| `REDIS_HOST` / `REDIS_PASSWORD` | 是 | Redis 地址与认证密码；本地开发端口仅绑定 `127.0.0.1` |
| `MINIO_ROOT_USER` / `MINIO_ROOT_PASSWORD` / `MINIO_BUCKET` / `MINIO_PUBLIC_ENDPOINT` | 是 | 对象存储；公网端点用于签名 URL |
| `JWT_SECRET` | 是 | ≥ 64 字节随机串 |
| `DATA_ENCRYPTION_KEY` | 是 | 32 字节 base64（`openssl rand -base64 32`） |
| `BAILIAN_API_KEY` / `BAILIAN_BASE_URL` | 是 | 阿里云百炼（Qwen、GLM、Embedding、Rerank） |
| `DEEPSEEK_API_KEY` | 是 | DeepSeek |
| `LLM_DEFAULT_TIER` | 否 | 默认 `FLASH` |
| `JOBS_MCP_URL` | 否 | 默认 `http://jobs-mcp:7001` |
| `SEARCH_MCP_URL` / `SEARCH_MCP_API_KEY` | 否 | 搜索 MCP（博查 / Tavily） |
| `GITHUB_MCP_URL` | 否 | 默认官方远程地址；用户 Token 在设置页录入 |
| `DEMO_ACCOUNT_ENABLED` / `DEMO_ACCOUNT_EMAIL` / `DEMO_ACCOUNT_PASSWORD` | 否 | 体验账号 |
| `CORS_ORIGINS` | 否 | 前端镜像部署（Vercel）时填写 |
| `CAMPUS_CALENDAR_SOURCE_URL` | 否 | 公开聚合 `jobs.json` 地址 |
| `SENTRY_DSN` | 否 | 错误上报（可选） |
| `VITE_API_BASE_URL` | 前端 | 同域用 `/api/v1`；分离部署用完整 URL |

密钥管理：

- `.gitignore` 忽略 `.env`、`.env.*`，保留 `*.example`。
- pre-commit 运行 `gitleaks protect --staged`；CI 运行 `gitleaks detect`。
- 服务器上 `.env` 权限 `600`；密钥泄露立即在百炼 / DeepSeek 控制台轮换。

## 8. 服务器初始化（一次性）

```bash
# Ubuntu 22.04 / 24.04，2C4G，开放 80/443
curl -fsSL https://get.docker.com | sh && sudo usermod -aG docker $USER
sudo mkdir -p /opt/offerpilot && sudo chown $USER /opt/offerpilot
git clone <repo> /opt/offerpilot && cd /opt/offerpilot
cp .env.example .env && chmod 600 .env && vim .env          # 填写密钥与域名
docker compose -f deploy/docker-compose.yml up -d
docker compose -f deploy/docker-compose.yml logs -f backend  # 等待 Flyway 完成、health UP
# 灌入种子数据（职业库、问卷、面经、体验账号）
docker compose -f deploy/docker-compose.yml exec backend java -jar app.jar --seed=all
```

域名 DNS A 记录指向服务器；Caddy 首次启动自动申请 Let's Encrypt 证书。

## 9. 备份、恢复与演示数据

### 9.1 备份（`deploy/scripts/backup.sh`，宿主机 cron 每日 03:30）

```bash
#!/usr/bin/env bash
set -euo pipefail
cd /opt/offerpilot
TS=$(date +%F_%H%M)
docker compose -f deploy/docker-compose.yml exec -T postgres pg_dump -U "$POSTGRES_USER" "$POSTGRES_DB" | gzip > "backups/pg_$TS.sql.gz"
docker run --rm --volumes-from offerpilot-minio-1 -v "$PWD/backups:/backup" alpine tar czf "/backup/minio_$TS.tgz" /data
find backups -type f -mtime +7 -delete
```

```bash
gunzip -c backups/pg_2026-11-20_0330.sql.gz | docker compose -f deploy/docker-compose.yml exec -T postgres psql -U "$POSTGRES_USER" "$POSTGRES_DB"
```

## 12. 评审期保障与故障手册

| 场景 | 处理 |
| --- | --- |
| 后端 OOM 重启循环 | `docker logs`; 降低 `MaxRAMPercentage` 或提升内存限制；检查 HNSW 建索引任务 |
| 模型全部 429 | `LLM_DEFAULT_TIER=CHEAP` 重启；启用缓存；必要时切换备用 Key |
| jobs-mcp 站点失效 | 应用自动跳过；如全部失效，设置 `JOBS_SOURCE_MODE=LOCAL` 使用缓存岗位库 |
| 证书申请失败 | 检查 DNS 与 80 端口；临时用 `tls internal` 并在 README 说明 |
| 磁盘满 | 清理 `docker system prune`、旧备份；`agent_events` 30 天清理任务是否运行 |
| 数据误删 | 用最近备份恢复（§9.2） |
| 演示期间流卡住 | 前端自动 `resume`；手动刷新；确认 Caddy `flush_interval -1` |

评审窗口内（提交后至评审意见发布）每日检查一次 UptimeRobot 与 `/admin/usage`；不做任何功能变更，仅允许紧急修复并记录。

# 真实岗位与简历匹配 · 2026-09-22

本次已完成岗位页到后端、MCP、企业官网及简历匹配模型的业务链路。

## 使用

1. 打开 `http://localhost:8080/jobs`，输入关键词，选择企业、校招/实习/社招和城市后搜索。
2. 进入岗位详情，获取完整详情；可以查看官网原岗位、收藏到本地看板。
3. 选择已经解析完成的简历及版本，点击生成匹配报告。
4. 报告逐项列出满足、部分满足和缺少证据，引用可定位岗位与简历原文；刷新后可从历史报告重新打开。

本地编辑器草稿尚未上传解析时不会出现在匹配简历选择框中。报告绑定分析时的简历版本和岗位快照，后续修改不会重写旧报告。匹配分数是模型提取要求的证据覆盖分，不是录用概率；原文校验能拒绝不存在的引用，不能保证模型对要求和能力的判断完全正确。

## MCP 接入位置

浏览器访问 `/api/v1/jobs`；后端 `JobsMcpClient` 向内置服务 `/mcp` 执行 initialize、initialized 和 tools/call，调用 list_sites、search_jobs、get_job_detail。前端无需直接持有 MCP 客户端或密钥。此次没有把聊天改成自主选工具的 Agent；自然语言条件拆解、批量简历排名、向量召回和自动投递仍未实现。

企业适配器可能超时或不支持某种筛选。页面区分部分站点失败、全站故障与真实空结果，保留来源、缓存及截断信息。已收藏看板仍保存在当前浏览器，不会发送真实投递。
